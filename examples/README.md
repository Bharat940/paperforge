# Engrapha Examples Directory

Welcome to the canonical reference examples for the Engrapha notes and diagrams compilation ecosystem.

## 🚀 Core Features

- [getting_started.py](getting_started.py): A minimal, 20-line compilation script demonstrating the fundamental imports, theme setup, cover, and document builder.
- [basic_notes.py](basic_notes.py): Showcases semantic document elements including headings, body text, tables, list formatting, and the 5 styled callout boxes.
- [formulas.py](formulas.py): Demonstrates LaTeX math rendering (inline and block equations), along with academic theorem and proof blocks.
- [diagrams.py](diagrams.py): Provides a consolidated showcase of the most popular native vector diagram builders (flowchart, state-machine, sequence, and ER diagrams).
- [markdown_cli.py](markdown_cli.py): Shows how to programmatically compile plain Markdown files to themed PDFs using the `compile_markdown_to_pdf` CLI module.
- [demo_comprehensive.py](demo_comprehensive.py): A comprehensive reference combining every notes and diagram feature into a multi-page textbook PDF.

## 📚 Subject-Specific Notes

These scripts show how to compile realistic academic semester notes:

- [subject/dsa_notes.py](subject/dsa_notes.py): Large, multi-page lecture notes for Data Structures and Algorithms complete with diagrams, complexity analysis, and interview Q&As.
- [subject/networking_notes.py](subject/networking_notes.py): Computer Networks notes featuring sequence flow diagrams (TCP handshake) and layered stack models.
- [subject/database_notes.py](subject/database_notes.py): Relational database guide with ER diagrams, database relational schema layout, and formatted SQL code blocks.

Canonical templates optimized for LLMs and autonomous software engineering agents:
